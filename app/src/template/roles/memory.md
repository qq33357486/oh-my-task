# 记忆用法（可选）
有 memos 工具才走本流程；没有就只用 knowledge/ 文件。
一个项目一个 user_id，不按角色拆。
1. 任务开始前搜一次
2. 命中只当候选，不当规则
3. 记录员在任务结束时写入
4. 写入前先搜，同类已有则不写
5. 整理员定期去重、提议晋升
- 搜索词用任务类型加关键词。
- 每次最多取 5 条命中。
- 与文件规则矛盾，以文件为准。
- 其他角色禁止写入，只写候选教训。
- 单条 ≤100 字，须含卡号和适用条件。
- 禁止写入密钥、整份文档、长文。
- 删除须整理员提议、人同意。
- 角色用内容前缀标注，如 [角色:检查员]。
- 各接口分工与冲突处理见 memory-tools.md。
