# 用内置浏览器核对页面

> 来自 2026-11-27 的任务 `entry-page-and-guide`（记录在它的 tasks.md「独立验收的记录」和「回做」里）。本机是 Windows，当时 ZCode 内置浏览器的内核是 Chromium 152（Electron 44）。别的机器、别的版本未必一样：下面每一条都是那天试出来的，换了个版本先试一下再信。

ZCode 的内置浏览器用来看页面实际排出来什么样：版式、自适应、滚动条、整页盖住的效果。它选不了目录，所以读写真实目录的那几步它代不了，那些见「浏览器目录访问的约束」里「怎么自动操作真实浏览器」。

## 怎么用

先加载技能 `browser-use:control-browser`，照它说的用 `mcp__node_repl__js` 控制。每一次调用都是新的运行环境，要照技能重新初始化，再按 id 取标签页。

- 开发服务器在 `app/` 下起（比如 `npm run dev -- --port 5178 --strictPort`）。内置浏览器只能用 `http://localhost:5178/` 打开，`127.0.0.1` 连不上。
- 改视口：`tab.setViewportSize({ width, height })`，改完等一两秒再取数（排版、字体、图片都要时间）。
- 在页面里取数：`tab.playwright.evaluate(...)`。位置用 `getBoundingClientRect`；文字本身的范围用 `Range.getClientRects`（字两端留白不算在里头）；某一点最上面一层是谁，用 `document.elementFromPoint`，不接鼠标事件的元素要临时让它接，量完恢复。
- 截图：整屏的 `tab.screenshot()` 才带滚动条；带 `clip` 的截图不带滚动条。整页截图（`fullPage`）拼接不对，不要用。截图偶尔超时，等一会儿再截，不要连着重试。
- 量具先校准：拿一处已知的位置对一对数，对上了再量别的。

## 坑

- 在页面里跑的代码，动态 `import()` 不能直接写，会被改写成一个不存在的 `importModule`。要拿到页面正在用的那一份模块（比如手里没进项目、想从 store 打开使用说明），写 `new Function('url', 'return import(url)')`；网址从 `performance.getEntriesByType('resource')` 里找页面实际加载的那一个（开发服务器热更新以后带 `?t=时间戳`），不然拿到的是另一份。
- 用定位器 `click()` 去点入口页环上的节点，等不到而超时。可以在页面里对那个元素调 `.click()`。
- 键盘试不出来：用 `cua.keypress` 按 PageDown、方向键、Tab，页面不滚、焦点也不动（没锁滚动时也一样）。键盘上的行为留给人。`cua.scroll`（滚轮）偶尔超时。
- 给根元素写 `color-scheme: dark`，配色是深了，滚动条还是浅的；再写 `scrollbar-color` 才变深。
- 整页盖在页面上的那一层盖不住底下页面的滚动条：它在窗口层，占 15px。开着时给根元素写 `overflow: hidden`，关掉时恢复。
- 竖向滚动条占 15px，各档都有：算内容宽度时记得减掉。
- 认领用户自己开着的标签页去量，视口就被改了（量完也是乱的）；在它上面 `tab.reload()` 有时候会变成空白页。要量就自己新开一个标签页，量完关掉；重新打开页面用 `tab.goto`，不用 `reload`。
- 看动效用定格：`document.querySelector('svg.ld-ring').pauseAnimations()`，再 `setCurrentTime(秒)` 拨到想要的时刻，截图。这个浏览器不画帧的时候，停住动画以后读到的坐标不跟着变，以截图为准；帧率也量不出来（`requestAnimationFrame` 不触发）。
- 这个工具自己的站点数据只有两样：IndexedDB 的 `oh-my-task-fs`（记住的目录）和 localStorage 的 `omt.recentProjects`（最近项目）。选过项目以后页面直接进项目，想再看入口页就把这两样清掉；同一个地址（localhost 的端口）上别的应用也有自己的键，别用 `localStorage.clear()`。

## 它代不了的

真机上的权限弹窗、选目录、微信 QQ 里的卡片，还有键盘上的行为。这些按任务夹的真机验收单由人点。
