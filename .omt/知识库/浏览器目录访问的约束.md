# 浏览器目录访问的约束

> 记于 2026-11-24。前四条来自浏览器文档和旧版的实践；哪些单测测不出来，是这次做 DJTASK 时确认的。

DJTASK 是纯前端网页，没有后端。读写本机目录全靠浏览器的 File System Access API。

## 约束

- 只有 Chrome、Edge 支持。别的浏览器打开时入口页照常显示，点了「开始享受」才提示「请用电脑上的 Chrome 或 Edge 打开」。
- 选目录和申请权限都必须由用户的点击触发，代码不能自己弹。
- 目录句柄可以存进 IndexedDB，刷新后还在。浏览器重启后权限失效，要用户再点一下。
- 读写权限一次申请完：选目录时用读写模式，点「开始享受」、向浏览器要回上次那个目录时也一样。初始化和更新不再另外申请。人 2026-11-24 定的。
- 网页跑不了命令，也看不到授权目录以外的任何东西。所以 OpenSpec 的初始化和更新只能人自己去跑，页面只提示。
- Chromium 往真实目录写文件时会拦一批文件名，见「浏览器拦截的文件名」。
- 项目目录在磁盘上被删除以后，对它的句柄再迭代条目，报「找不到」（`NotFoundError`）。出处是 File System Access 规范第 2.4.1 节，2026-11-24 查。被改名的情况真机确认了也是「找不到」，见下面「真机确认过的事实」。句柄失效以后取什么都是「找不到」，页面上会被当成一个空目录，所以要先看目录本身还列不列得出来。
- 按文本读文件（`File.text()`）会去掉开头的 UTF-8 BOM；编码不对也不报错，会解成乱码。要管编码得按字节读（`arrayBuffer()`）。根 `AGENTS.md` 是唯一会被改写的已有文件，又不备份，所以按字节读。
- 按字节读再严格解码，拦得住带 BOM 的 UTF-16 和含中文的 ANSI，拦不住不带 BOM 的 UTF-16：西文后面跟一个零字节，整份恰好是合法的 UTF-8。正文里有零字节就该认不出（2026-11-24 第四轮独立验收实测）。只有英文的 ANSI 文件本来就是 UTF-8。
- 浏览器自己的存储（IndexedDB、localStorage）可能读不了或写不进去。记住目录和最近项目存在这里，只是为了方便：读不了、写不进去时照常工作，页面不能停在空白。

## 单测测不出来的

单元测试用的是内存里的假目录，下面这些只有真实目录句柄才会触发：

- 权限的查询和申请。
- Chromium 对文件名的拦截。
- 选目录的弹窗。
- 项目文件夹被移动、改名、删除以后，句柄报什么错。

所以读写真实目录的行为，要在真实浏览器里点过才算数。假目录能证明的只有「逻辑对」和「展示路径不写文件」。

## 真机确认过的事实

2026-11-24 在 RoxyBrowser 的「日常通用」窗口（Chromium 157 内核）里走通 DJTASK 的真机验收时确认的。人定了：这一块走通过一次就够，相关内容不变就不重测。

- **选一个新目录时**，选完浏览器会问「要允许这个网站编辑文件吗？」，按钮是「不允许」「允许」。每个新目录问一次。同一个目录之后再从菜单切过去，不问。
- **浏览器重启以后**权限失效，点「继续打开」弹的是「查看和编辑上次访问这个网站时的文件」，列出上次授权过的目录，按钮有三种：「不允许」「这次允许」「每次访问时允许」。点「不允许」之后再来一次，浏览器会重新弹出提示，没有记住拒绝。
- **页面开着时把项目文件夹改名**，下一轮读取时句柄报的就是「找不到」。Windows 没有因为浏览器开着而拦住改名。
- **把文件设成只读**，浏览器写它会失败，报的是 `NoModificationAllowedError`（「Cannot write to a read-only file」）。
- **框架名单上的 10 个文件都写得进去**，包括中文文件名的 `默认工作流.md`、`.yaml`、`.md`，没有被拦截。写出来的是 LF 换行，和源头一致。
- **在页面初始化过的目录里跑 `openspec init --tools zcode --scope project`**，OpenSpec 不追问，直接装好。
- **带 BOM 的 UTF-8 根 `AGENTS.md`**，页面改写后 BOM 还在文件最前面。
- 指纹浏览器的窗口走了代理，用 `http://127.0.0.1:…` 打不开本机的开发服务器（超时），要用 `http://localhost:…`。

## 怎么自动操作真实浏览器

- 用界面自动化（ZCode 的「电脑操作」）。点页面的「开始享受」（第一次来、没有上次的项目时，点它弹出选目录的窗口），系统的弹窗是另一个进程的窗口，标题是「選取這個網站儲存變更的位置」；把路径填进它的「文件夹:」框，点「选择文件夹」，再回到浏览器点权限提示里的「允许」。
- 不要用 Playwright 这类接管工具。它一连上就打开「截住选文件弹窗」的开关，只有它自己能关。开关开着时选目录的弹窗一出来就被取消，人手动点也不行。
- 浏览器窗口里页面上的文字很长时，界面树只给前 400 个元素，后面的要靠截图看。

## 测试里怎么绕

- 把页面的目录访问包成一层接口（`app/src/fs/types.ts` 的 `FsDir`），测试里换成内存里的假目录。
- 「记住目录」在测试里换成内存里的替身：真句柄能存进 IndexedDB，假句柄带着函数，存不进去。
