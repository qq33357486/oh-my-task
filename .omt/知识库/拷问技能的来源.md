## 怎么来的

- 这三个技能原本装在用户级目录 `~\.agents\skills\`，不在任何 git 仓库里。
- 2026-11-24 复制进 oh-my-task 仓库的 `.agents/skills/`，成了项目级的框架文件；用户级的那份随后删除。`~\.agents\skills-backup\` 里还留着 domain-modeling 的上游原件。
- 人说许可证无所谓，要求定期更新（2026-11-24）。

## 更新时注意

- grilling 直接用上游的。
- domain-modeling 要把本地改动合并进去。
- 更新后跑框架名单的测试：逐字比对磁盘文件，技能目录里没有漏掉的文件。
- 上游会变。比对办法：逐个文件取上游当前内容，和本地的逐行比；提交日期和说明用 `gh api "repos/mattpocock/skills/commits?path=<路径>"` 查。
