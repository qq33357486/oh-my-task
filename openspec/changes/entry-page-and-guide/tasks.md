## 真机验收单（验收时由人在真实的 Chrome 或 Edge 里点，AI 代不了）

前提：待办已全部勾完。开发服务器由 AI 起好。其中「用别的浏览器打开」这一步要重测：工具开发工作流里写过它不测，但这次那一块的行为改了，按它说的「改到的那块决定重测」。

- 第一次打开（这个地址以前没用过，或者先清掉站点数据）：看到首屏，标题是「只做决策，不碰文档。」，按钮是「开始享受」，左边是方形的环，右边讲的是需求。把浏览器窗口拉到页面可视区正好 1280×640（用开发者工具的设备模拟最省事）：首屏不滚动就能看全。
- 依次点环上的五个节点：右边跟着换。环上没有箭头，环下没有说明句，光点在走。
- 往下滚：三段，最后是「只做决策，不碰文档。」和「开始享受」。
- 点「开始享受」，选一个已经初始化过的目录：进入看板。
- 刷新页面：两种结果都算过，把看到的是哪种记下来。一是直接进到这个项目，中间不出现入口页（权限还在）。二是停在入口页，点「开始享受」、允许后才进（权限不在）。
- 关掉浏览器再打开：停在入口页，只有「开始享受」一个按钮。点它，浏览器弹权限提示，点允许：回到这个项目。
- 再关掉浏览器打开一次，点「开始享受」，这次在权限提示里点不允许：出现出错提示，里面有「选择目录」。点它，能选别的目录。
- 想换一个项目：进项目以后点页眉的「切换目录」，选别的目录，能换过去。
- 上次的目录被移走再打开：关掉标签页，在资源管理器里把这个项目的文件夹改个名，再打开页面。看到的是入口页，「开始享受」上方写着这个目录打不开了，提示里有「选择目录」。页眉的「切换目录」菜单里没有它了。看完把文件夹改回原名。
- 在看板点页眉的「使用说明」：整页，深色，三节。点右上角的「回到看板」：回到看板。
- 用别的浏览器（比如 Firefox）打开：入口页照常，没有那句提示。点「开始享受」：按钮下方出现「请用电脑上的 Chrome 或 Edge 打开，才能选择项目文件夹。」
- 看一眼整体：入口页、首屏以下、使用说明好不好看。
- 把窗口拉到 760 以下宽：首屏排成一列（标题和副标题、「开始享受」、循环、说明），没有横向滚动条。
- 把地址发到微信或 QQ 里，看卡片有没有标题、描述和预览图。
