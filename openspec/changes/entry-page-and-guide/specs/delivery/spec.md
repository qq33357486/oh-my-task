# Spec Delta

## MODIFIED Requirements

### Requirement: 浏览器

> 出处：人类的原话『请在电脑上打开这个提示不需要，而是用户点击后再提示。』；提示的原句是人类答复 AI 假设时的原话『其他都ok』（原 AI 假设 2）

网页 SHALL 能在 Chrome 和 Edge 的当前稳定版里完整使用。在别的浏览器里打开时，按 entry-page「浏览器不支持时」处理：入口页照常显示，用户点了「开始享受」才出现那句提示，不显示看板。

#### Scenario: 用 Firefox 打开

- **WHEN** 用户用 Firefox 打开页面
- **THEN** 入口页照常显示，不显示看板；那句提示要等用户点了「开始享受」才出现

#### Scenario: 页面刚打开

- **WHEN** 页面刚打开，还没读完浏览器里存了上次的哪个目录
- **THEN** 页面是空白的，不先显示入口页再换成别的

### Requirement: 提示说人话

> 出处：人类的原话『Q4 改成：“开始享受”』『再次打开页面，如果已有加载工程，默认加载进入，不用让用户再选一次。』；这一条的前两段和三个场景名都不动，只把两个场景里说到的旧按钮换成现在的样子

页面任何一步没成功时，系统 SHALL 用一句人话说清什么没成功、下一步做什么。技术细节只进浏览器控制台。

「记住上次打开的目录」和「最近打开过的项目」存在浏览器自己的存储里，只是为了下次方便。存储读不了、写不进去时，系统 SHALL 照常工作：能选目录就选，能打开就打开，不停在空白页。

#### Scenario: 目录读不出来

- **WHEN** 读当前目录时出错
- **THEN** 页面显示一句人话和下一步，原始错误信息只出现在控制台

#### Scenario: 打开页面时读不到浏览器里存的东西

- **WHEN** 页面启动，读「上次打开的是哪个目录」时出错
- **THEN** 页面显示入口页，上面有「开始享受」按钮，不停在空白页

#### Scenario: 记不住这次选的目录

- **WHEN** 用户选了一个目录并授权，浏览器没能把这个目录记下来
- **THEN** 这个目录照样打开；只是下次打开页面时回不到它，要重新选一个目录
