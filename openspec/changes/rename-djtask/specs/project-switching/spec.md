# Spec Delta

## MODIFIED Requirements

### Requirement: 未初始化的目录

> 出处：人类的原话『给这个项目起个名字，叫多杰任务系统。 DJTASK』；文案细节经人类回答『全按建议定（推荐）』确认

选定的目录没有 `.omt/` 时，系统 SHALL 不显示看板，显示一句「这个目录还没有任务系统」、一个「初始化此目录」按钮，和 OpenSpec 的安装提示。目录含 `.oht/`（旧版）时，系统 SHALL 改为显示「这个目录装的是旧版 DJ Task，先删除 `.oht/` 再初始化」，不给可点的初始化按钮。

#### Scenario: 打开空目录
- **WHEN** 用户选定一个既没有 `.omt/` 也没有 `.oht/` 的目录
- **THEN** 页面显示上述文字、按钮和提示，不显示四列看板

#### Scenario: 打开带旧版的目录
- **WHEN** 用户选定一个有 `.oht/`、没有 `.omt/` 的目录
- **THEN** 页面显示那句旧版提示，没有可点的初始化按钮，目录没有任何变化
