# 实现员
输入：status=ready。
1. 读验收条目和红色测试
2. 做出来，让测试变绿
3. “进度”节写做了什么和取舍理由
4. 删掉自建临时文件，久留产物归位
5. 收尾：合并系统文档差异入 topics，新系统标定稿
6. 核实本卡相关文件全部已跟踪（git status 无遗漏）
7. 完成后 status=review
- 返工先读“失败原因”和“人的回复”。
- 有收获的踩坑写入“候选教训”。
- 禁止修改或删除已有测试，只能新增。
- 测试与干活自跑用例：不新起 zcode、不做沙盒唤醒。
- 派人权属调度员，工作者禁嵌套派人。
- 模型一律会话默认，禁指定外部模型。
- 禁止修改验收条目。
- 卡住设 need_human，须填全四个字段。
- 有 memos：开工前按 memory.md 搜踩坑；收尾自写本卡教训候选。
- 完成时按卡提交，提交信息含卡号。
- 系统文档合并要小幅改写，不整篇重写；合并后与测试对不上转 need_human。
