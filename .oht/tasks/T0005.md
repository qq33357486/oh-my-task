## 需求
背景：T0002 迁移后 `python -I .oht/scripts/check-card.py .` 是假通过——脚本 glob 是 `ROOT/tasks/*.md`，根目录已无 tasks/，扫到零张卡仍 exit 0 静默通过；真校验须用无参形式（默认 ROOT=.oht/）。扫不到文件时静默通过比报错更危险（见 knowledge/log/2026-11.md"glob 为空时检查器 0 超限假绿"条）。

改动对象：.oht/scripts/check-card.py、.oht/scripts/check-size.py（属框架只读区，修改须人批准，见复述卡待你定）。

要求：
1. 零匹配报错：目录扫描模式下，check-card.py glob 零张卡、check-size.py 待检文件全部不存在（实际校验数为 0）时，输出明确提示（如"未扫描到任何卡片，请确认 ROOT 路径"）并 exit 非 0。
2. 正常扫描不受影响：扫到卡片/文件时，现有校验逻辑与输出格式（"超限 N 处"）保持不变。
3. 无参运行默认 ROOT=.oht/ 的行为保持不变。
4. check-card.py 传单张卡片路径（ONLY 模式）不属于零匹配场景，不受影响。
5. 两脚本 docstring 的用法行同步更新，说明零匹配时的行为。

## 复述卡

3. 例子：跑 `check-card.py .`（根下已无 tasks/）报"未扫描"且非 0；无参跑仍 0。
