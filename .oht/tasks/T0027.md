## 原话
"方块间的箭头，检查至记录那，箭头好像也有渲染错误。检查与实现，双向箭头，就弄两线，不同弧度，不要重叠。"（人，2026-11-03）

## 需求
人看流程图发现两处连线缺陷（原话：检查至记录那箭头有渲染错误；检查与实现双向箭头要两线不同弧度不重叠）：

**缺陷 1：连线端点悬空（检查→记录段最明显）**
现有 `FlowView.tsx` 用 `anchorToward`：自节点中心朝弧中点方向外推**固定距离** `NODE_REACH=152px` 取端点。节点盒半宽 130、半高 110 均小于 152，端点悬在盒外 22~42px，箭头不贴节点；「检查→记录」弧中点方向近水平（162°），悬空量最大、最显眼。

**缺陷 2：检查⇄实现两线完全重合**
顺序线「实现→检查」的弧中点 `midDeg=(54+126)/2=90`，回边「检查→实现」硬编码 `midDeg=90`——两线弧中点同点、端点同点，路径逐点重合，双向箭头堆在一起分不清（原话点名处）。

**修法（新建 `app/src/lib/flowGeometry.ts` 纯函数，FlowView 只做接线）：**

导出 `computeLink(from: NodeBox, to: NodeBox, sag: number, gap?: number): { d: string; apex: Vec; side: Vec }`，`NodeBox = { x, y, w, h }`（盒左上角 + 宽高）：
- 端点：从盒中心沿弦方向（指向对盒中心）与盒边界求交（射线-矩形 slab 交点），再沿弦方向外推 `gap`（默认 6px）——端点恒在盒外 6px、贴边缘，随盒尺寸自适应，悬空根除。
- 弧：端点连线为弦（长 `L`），法线 `n = perp(弦方向)`（固定手性，如 `(-uy, ux)`）；控制点取弦 1/3、2/3 处沿 `n` 偏移 `2*sag*L`，输出三次贝塞尔 `M ... C ...`（弧顶 ≈ 弦中点沿 `n` 偏 `1.5*sag*L`）。正反向互调时弦方向反向、`n` 随之反向——**A→B 与 B→A 弧自动分居弦两侧，无需任何特判**。
- 返回 `apex`（弧顶点，t=0.5 处贝塞尔点）与 `side`（指向弧凸侧的外法向单位向量，标签定位用）。

`FlowView.tsx` 接线：
- 节点盒由 `itemPos`（左上角）+ `NODE_W=260` + 新常量 `NODE_H=280` 构成；中心即盒中心（`nodeCenter`/`NODE_ANCHOR_DY` 语义废除）。
- 六条线全走 `computeLink`：顺序四段（需求→测试→实现→检查→记录）`sag=0.15`；回边「检查→实现」`sag=0.22`（打回弧，与顺序弧不同弧度）；回边「记录→需求」`sag=0.15`（闭合段）。`d` 仍由 `itemPos` 实时推导（拖节点跟随，既有用例锁定该性质）。
- 回边标签位改 `apex + side * 22`（旧 `labelPos(mid, 40)` 删除）；按默认布局，打回弧顶在弦下方约 116px（环底外侧），标签随行。
- 椭圆轨道装饰线 `cy` 改 `RING_CY + NODE_H/2 = 740`（跟随节点中心带；`cx/rx/ry` 不变）。
- `FIT_CONTENT.maxY` 同步 `1226 → 1286`（检查/实现 top 916 + NODE_H 280 + 原余量 90），保 fit 居中不截底。
- CSS（`app/src/index.css`）：`.flow-node` 的 `min-height: 220px` 改 `height: 280px`；`.flow-node__cards` 加 `flex: 1 1 auto; min-height: 0`（固定高下卡区收缩滚动，替换现 `max-height: 240px` 方案）。
- 删除仅剩自引用的死代码：`anchorToward`、`arcPath`、`labelPos`、`NODE_REACH`、`NODE_ANCHOR_DY`、`nodeCenter`、环弧 `midDeg` 推算（已核实无测试或其他模块引用）。

**取舍理由（自治，白名单外）：**
- 改「贴边求交 + 法线弧」而非继续环弧近似：环弧锚点与盒尺寸解耦是悬空根因；贴边后纯函数性质（端点、分离）可直接单测，jsdom 与真实浏览器同源。
- `NODE_H` 做成 JS 常量并同步 CSS：jsdom 不应用 CSS（T0019 教训），连线端点计算须两侧取得同一盒高；280 ≈ 现实际渲染高度（标题栏 36 + 卡区 240 + padding），视觉高度基本不变。
- A2 用「d 采样最小距离」断言而非快照：锁「不重叠」本质，红（重合≈0）绿（>190px）区分明确，不锁死具体坐标值。

**约束：**
- DOM 契约零改动：`data-flow-edge`（恰两条回边）、`data-flow-link`（恰四条顺序线）、`data-flow-ring`、`data-flow-node`、`data-flow-text="edge-label"` 等既有契约原样保持；既有环形几何用例（包围盒高宽比 ≥0.35、多边形面积比 ≥0.25）不得破坏。
- `d` 含 `C`：新实现显式产三次贝塞尔；既有锁定断言为含 `[CSQ]`（A6），`C` 是其子集，兼容不冲突。
- 既有测试文件零改动（本卡新增测试文件除外，属检查员职权）；全量 vitest 全绿且 ≥100 用例（当前基线 24 文件 100 用例）、`npx tsc --noEmit` 退出码 0。
