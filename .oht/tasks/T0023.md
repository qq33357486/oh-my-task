## 原话
"之前是由 GLM 完成了整个项目的初始化和页面。我希望你检查是否有优化空间，特别是页面能否更漂亮。"（人，2026-11-03；范围定为"全站视觉统一"，拆三卡，本卡是第 2 张：设计令牌 + 页眉 + 看板 + 全文弹层。）
补充（人）：执行实现的是审美较弱的 GLM，所以方案必须给到具体数值，实现员照数值做，不自行发挥配色。

## 需求
目标：建立全站统一的设计令牌（颜色、圆角、阴影、字体），并用它重做页眉、看板列、卡片、归档行、全文弹层的外观。风格定位：**克制的"工具型"界面——浅灰底、白卡片、靛蓝主色，页眉深色且与流程图画布同色**。不加图片资源，不引入新依赖，全部用 CSS 与 AntD token。

### 0. 硬约束（先读）
- **卡面信息契约不变**（T0017 人定案）：常规卡卡面只显示"标题 + 编号小 Tag"，其他信息一律不上卡面；title 为空时以编号文本主显。
- **DOM 契约不变**：`data-column` 列序、`data-urgent` 条件语义、`data-card-id`、`data-recorded-row`、点击卡开弹层、页眉"流程图/看板"两个原生 button 的文本与 DOM 序（流程图在前）、两视图并存渲染（`display:none` 切换）。
- **不动**：`FlowView.tsx`、`flowMap.ts`、`NoProject.tsx`、`store.ts`、任何解析/扫描逻辑。入口页与流程图归 T0024。
- 先读 `Kanban.tsx`、`App.tsx`、`index.css` 的看板段与页眉段，再动手。已有测试（`src/components/__tests__`、`src/lib/__tests__`）是锁定的，只增不改。
- 看板相关选择器里不得再硬编码旧 AntD 预设状态色（`#ff4d4f #2f54eb #13c2c2 #722ed1 #52c41a`），一律走变量。

导出三个常量，值必须**逐字**如下：
```ts

export const FONT_FAMILY =
```

### 3. 页眉（`.app-header` 系列；`App.tsx` 只允许加 className 与一个 logo 元素）
- 背景 `var(--oht-header-bg)`；`.app-header` 加 `position: relative`；底部 2px 渐变线：`.app-header::after { content:''; position:absolute; left:0; right:0; bottom:0; height:2px; background: linear-gradient(90deg, #4f46e5, #06b6d4); }`；去掉原 `box-shadow`。
- 标题"循环工程任务看板"：17px、font-weight 600、颜色 #fff、letter-spacing 0.02em。标题前插 `<span className="app-header__logo" aria-hidden="true" />`，样式 24×24、圆角 7px、`background: linear-gradient(135deg, #4f46e5, #06b6d4)`、与标题间距 10px。
- 目录名 Tag：不再用 `color="blue"`；改为 `<Tag bordered={false} className="app-header__root">`，样式：背景 `rgba(255,255,255,0.08)`、颜色 #c7cbd6、圆角 6px、等宽字体（Consolas, Menlo, monospace）12px。
- 视图切换（`.app-header__views`，两个原生 button 文本/顺序不变）做成分段胶囊：容器 `background: rgba(255,255,255,0.08); border-radius: 9px; padding: 3px; display:inline-flex; gap:2px`；按钮 `height:28px; padding:0 16px; border:0; border-radius:7px; background:transparent; color:#aab0bf; font-size:13px; cursor:pointer; transition: background .15s, color .15s`；hover 颜色 #fff；激活态 `.app-header__view-btn--active` 背景 #fff、颜色 #17171b、font-weight 600。
- "仅 Chrome/Edge 支持"与"上次刷新 HH:MM:SS"：12px、颜色 `rgba(255,255,255,0.45)`，后者加 `font-variant-numeric: tabular-nums`。
- 刷新按钮（页眉内 `.ant-btn`）：背景 `rgba(255,255,255,0.08)`、边框 `1px solid rgba(255,255,255,0.18)`、文字 #fff；hover 边框 #fff、背景 `rgba(255,255,255,0.14)`；loading 态保持 AntD 默认。

### 4. 看板列
- `.kanban__columns` gap 16px 不变，`padding: 4px 2px 12px`。
- `.kanban__column`：背景 `#eceef4`、**无边框**、圆角 12px、内边距 12px、`min-width: 200px`（原 176）、`flex: 1 1 0` 不变。
- 列头 `.kanban__column-head`：左侧状态圆点（8×8、圆形、`background: var(--oht-st-<status>)`，通过现有 `data-column` 属性选择器上色，如 `.kanban__column[data-column="ready"] .kanban__column-head::before`，七列各一条）+ 列名 13px/600/`var(--oht-text)`；右侧计数改为胶囊：`min-width:20px; height:20px; padding:0 6px; border-radius:10px; background: rgba(16,24,40,0.07); font-size:12px; color: var(--oht-text-2); display:inline-flex; align-items:center; justify-content:center`。**计数文本必须仍在原元素里**（已有测试按文本断言），只改样式；若原来用 AntD `Badge`，加 className 覆盖，不删组件。
- need_human 列有卡时（`.kanban__column--urgent`）：背景 `#fef2f2`、`border: 1px solid #fecaca`、去掉原 inset 阴影；列头文字 `#dc2626`；圆点加呼吸动画：`@keyframes oht-pulse { 0%,100% { box-shadow: 0 0 0 0 rgba(239,68,68,.45) } 50% { box-shadow: 0 0 0 5px rgba(239,68,68,0) } }`，2s infinite。必须同时写 `@media (prefers-reduced-motion: reduce) { .kanban__column--urgent .kanban__column-head::before { animation: none; } }`。
- **空列占位**：某列没有卡时，卡片区渲染 `<div className="kanban__empty" data-empty-column>暂无任务</div>`；样式 `height:72px; display:flex; align-items:center; justify-content:center; border:1px dashed #cfd4e0; border-radius:8px; color: var(--oht-text-3); font-size:12px`。有卡的列不出现该元素；recorded 列无归档行时同样显示。

### 5. 卡片与归档行
- 卡片（`.kanban-card .ant-card`）：背景白、`border: 1px solid var(--oht-border)`、`border-inline-start: 3px solid var(--oht-st-<status>)`、圆角 10px、`box-shadow: var(--oht-shadow-sm)`；`.kanban-card` 外层 `cursor: pointer`；hover：`transform: translateY(-1px); box-shadow: var(--oht-shadow-md)`，`transition: transform .15s, box-shadow .15s`。六个状态的左边条色改走 `var(--oht-st-*)`（选择器沿用现有 `.kanban-card--<status>`）。
- 卡内：标题 13px/600/`var(--oht-text)`，单行省略（现状保持）；编号 Tag 保持中性小号，等宽 11px，颜色 `var(--oht-text-2)`、背景 `#f2f4f7`、无边框（覆盖 `.kanban-card__num.ant-tag` 与 `.kanban__row-num.ant-tag`）。
- 归档行 `.kanban__row`：padding `8px 6px`、分隔线 `1px solid var(--oht-border)`、hover 背景 `rgba(79,70,229,0.06)`；`.kanban__row-title` 颜色 `var(--oht-text-2)`。
- 降级区 `.kanban__strays`：保持黄色提示语义，圆角改 12px，其余不动。

### 6. 全文弹层（点卡打开的 Modal，代码在 `Kanban.tsx`）
- 头部字段区（id、status、type、round、question、stop_reason 等现有字段文本全部保留）：id 与 status 用 AntD `Tag`，status Tag 的 `color` 取 `STATUS_COLORS[status]`（未知状态用 `#9ca3af`），加 `bordered={false}`，文字白色。
- 字段行：标签列 80px 宽、颜色 `var(--oht-text-2)`、12px；值列 13px。
- `question` 与 `stop_reason` 若非空，各渲染为 callout：`<div className="card-callout card-callout--danger">`，样式 `background:#fef2f2; border-left:3px solid #ef4444; border-radius:6px; padding:8px 12px; color:#7f1d1d; font-size:13px; line-height:1.6`。文本内容与之前一致。
- 正文 markdown 区（`.md-text`）：`line-height: 1.7`；`pre` 背景改 `#f4f5f9`、边框 `var(--oht-border)`、圆角 8px；`code` 背景 `#f2f4f7`。弹层 body `max-height: 70vh; overflow-y: auto`。
