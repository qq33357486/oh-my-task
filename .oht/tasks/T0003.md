## 原话
（继承自 T0001 拷问决策 1、2、6、8、9：很轻的前端，无后端，File System Access API 读本地任务显示在画布上看板；真正的工作在本地 Agent 和 AI 之间完成）

## 需求
在 `app/` 新建纯前端项目，实现任务看板。本卡只做"读+显示"，不做初始化（T0004 做）。

技术栈：React 18 + Ant Design 5 + Zustand + Vite + TypeScript。从 `D:\git\DJUI\editor\frontend\src\fs\fsAccess.ts` 拷贝通用文件层（可裁剪），参考其 `projectContext.ts` 的句柄持久化（IndexedDB）模式。

功能：
1. 选择目录：按钮触发 `showDirectoryPicker({ mode: 'read' })`；句柄存 IndexedDB，刷新后自动尝试恢复，权限失效时引导重授权。
2. 解析任务卡：扫描 `<根>/.oht/tasks/*.md`，跳过 `_*.md`；解析 frontmatter（id、type、status、round、parent、origin、lane、batch）与正文九节标题；解析失败的单卡降级显示（标"解析失败"），不影响其他卡。无 `.oht/` 时显示"该目录未初始化循环工程"提示。
3. 看板：列固定顺序 need_human、new、tests、ready、review、done、recorded；need_human 列红色高亮且固定在最左；卡片显示 id、原话首行（≤40字）、round>0 时标 round 数；点击卡片弹出全文（markdown 渲染，含验收条目状态）。
4. 刷新：5 秒轮询重扫目录；手动刷新按钮。
5. 页眉显示所选目录名与"仅 Chrome/Edge 支持"提示（Firefox/Safari 检测到无 API 时显示降级说明页）。

约束：
- 纯前端，禁止任何后端/服务器代码；所有文件访问走 File System Access API。
- 解析逻辑（frontmatter/正文切分）写成与文件系统无关的纯函数模块，供单测与 T0004 复用。
- 中文 UI。
