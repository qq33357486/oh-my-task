## 原话
"右上角选项卡，渲染有问题。"（人，2026-11-03）

## 需求
页眉右上角「流程图/看板」分段选项卡渲染修正（人原话仅"渲染有问题"，两处病灶经代码核实）：

1. 文字垂直不居中：AntD `Layout.Header` 默认 `line-height: 64px`，`app/src/index.css` 页眉区无任何行高重置；胶囊容器 `.app-header__views` 与按钮 `.app-header__view-btn`（height: 28px）继承 64px 行高，行盒与 28px 内容区错位，字形不在按钮内垂直居中（偏上/偏下随浏览器按钮内部布局实现而异，不断言方向，修法一致）。
2. 刷新按钮位移抖动：`App.tsx` 刷新 `<Button loading={loading}>` 触发 loading 时插入图标（约 14px + 8px 间距），按钮约 60px→82px 变宽；页眉 flex `space-between` 右缘固定，左侧选项卡被向左挤，每 5 秒轮询抖一次。

**修法（纯 CSS 三处 + 一处 className，无其他 JSX/逻辑改动）：**

- `index.css` `.app-header__views` 规则块内追加 `align-items: center; line-height: 1;`（切断 64px 继承；flex 使胶囊整体垂直居中于页眉）。
- `index.css` `.app-header__view-btn` 基础规则块内追加 `line-height: 28px; white-space: nowrap;`（文字在 28px 内自行居中，禁换行）。
- `index.css` 新增规则 `.app-header .ant-btn.app-header__refresh { min-width: 88px; }`（88px ≥ loading 态实宽约 82px，两态等宽零位移；不碰既有 ghost 样式选择器 `.app-header .ant-btn:not(.app-header__view-btn)`）。
- `App.tsx` 刷新 `<Button onClick={() => void refresh()} loading={loading}>` 加 `className="app-header__refresh"`。

**不得改动：**`.app-header__views` 的 `display/gap/background/border-radius/padding`（cssTokens.test.ts 锁定 `rgba(255, 255, 255, 0.08)`、`border-radius: 9px`）；`.app-header__view-btn` 的 `height/padding/font-size/color` 与激活态（同测锁定 `#17171b`）；appHeader.test.tsx 锁定的按钮文本「流程图/看板」与 DOM 序；任何测试文件。

**测试分层依据（knowledge/log 2026-11 T0019 条）：** vitest 不应用 CSS、jsdom 无布局，计算样式不可测 → auto 锚一律断言 index.css / App.tsx 文本（沿用 cssTokens.test.ts 的 ruleBlock 文本锚先例）；真实观感归 A4 人看。

**基线（2026-11-03 定稿时实测）：** `cd app && npx vitest run` 24 文件 100 用例全绿；`npx tsc --noEmit` 退出码 0 无输出。

## 复述卡
1. 理解：右上角选项卡文字没居中，刷新转圈时按钮变宽把选项卡挤得抖动。
2. 做：CSS 三处——选项卡容器与按钮重置行高、刷新按钮锁最小宽 88px；再给刷新按钮加个类名。不做：其他布局与视觉。
3. 例：点刷新触发 loading，「流程图/看板」文字居中、纹丝不动。
4. 拆分：无。
5. 待你定：无。

- 2026-11-04｜T0025｜用 `<Button[^>]*>` 类正则扫 JSX 开标签做文本锚时｜箭头函数 props（`onClick={() => …}`）里的 `>` 会提前终结匹配，捕获段截断于 `=>`，其后属性全丢失；被锚属性须写在首个 `>` 之前，或锚改用按标签配对解析（实证：T0025/A2 首版 className 排 onClick 后实跑红，属性序前移后绿）。｜0｜候选
- 2026-11-04｜T0025｜并行泳道同仓在途、全量失败清单随时漂移时｜「零回归」不能拿卡面旧基线比对（清单早已被并行卡推进改写），要受控 A/B：只还原本卡 delta 跑改前态、恢复后跑改后态，两清单逐项相同才证零回归（实证：T0025 收尾 A/B 两侧 7 文件 6 用例逐项相同，定版全量漂移至 5 用例全归属 T0026/T0027）。｜0｜候选
